# Webloc Thumbnails

Give `.webloc` shortcuts a website screenshot icon in Finder

## Install and use

1. Run the installer:
   ```sh
    bash scripts/install.sh
   ```

   This builds a release app, signs it locally, installs it in `~/Applications`, and registers **Generate Website Thumbnails** with Finder.

2. Select `.webloc` files in Finder and choose **Services → Generate Website Thumbnails**
